Lector de partidas: código de terceros usado como referencia (tools/savereader)
================================================================================
El lector de partidas que se ejecuta dentro de la aplicación (api/app/savereader) es una PORTACIÓN A PYTHON
del código C# de referencia que está en tools/savereader (carpeta Vendor y THIRD_PARTY). Ese código C#
no se incluye en el ejecutable; solo se usó para generar las tablas y la lógica del lector. Todo se usa en
modo solo lectura: no se distribuye código de cifrado (se eliminó EncryptRegion de MHWCrypto).

================================================================================
WorldChunkTool (herramienta de desarrollo, NO se distribuye)
================================================================================
El repositorio solo contiene un Dockerfile y un parche (tools/worldchunktool) que compilan desde su código
fuente el proyecto original WorldChunkTool de MHVuze (https://github.com/mhvuze/WorldChunkTool), en un commit
fijado. Ni el código ni el ejecutable se incluyen en el repositorio ni en los paquetes. Se usa solo para que
cada usuario extraiga los iconos de su propia copia del juego. Para su licencia, consultar la licencia del
proyecto original.


================================================================================
Oodle (oo2core) y GSAP: NO se distribuyen
================================================================================
- La biblioteca Oodle (oo2core_*_win64.dll) es software propietario de RAD Game Tools / Epic Games y NO se
  distribuye con este proyecto. WorldChunkTool la necesita en tiempo de ejecución; cada usuario debe obtenerla
  por su cuenta.
- GSAP (GreenSock) tiene licencia propia y NO se distribuye: solo se usa en la carpeta design/ para regenerar
  el arte de la interfaz y no forma parte del repositorio ni de la aplicación.
